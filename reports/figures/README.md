# Figure provenance

All figures are generated by `complaints/plots.py` during `train.py`, from the measured experiment and frozen predictions. No figure values are manually invented. All included data is synthetic.

- `confusion_matrix.png`: frozen test predictions at the validation-selected cutoff.
- `roc_precision_recall.png`: frozen test scores and labels.
- `threshold_tradeoff.png`: validation data only.
- `feature_importance.png`: five validation shuffles per raw feature, measured by average-precision drop.
- `model_comparison.png`: five-fold training cross-validation mean and standard deviation.

Running `train.py` replaces the figures. The plotting code uses fixed styling, not AI-generated raster artwork.
